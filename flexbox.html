O que é Flexbox?

Flexbox é um recurso do CSS que ajuda a organizar elementos em uma página, facilitando o alinhamento e a distribuição dos espaços.

Principais propriedades

display: flex;

Ativa o Flexbox em um elemento.

justify-content

Organiza os elementos no eixo principal.

align-items

Alinha os elementos no eixo transversal.

flex-direction

Define se os elementos ficam em linha ou coluna.

flex-wrap

Permite que os elementos passem para outra linha.
