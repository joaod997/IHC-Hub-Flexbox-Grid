CSS Grid

Aprenda a organizar elementos em linhas e colunas

Início Flexbox Grid

O que é Grid?

CSS Grid é um recurso do CSS que permite organizar elementos em linhas e colunas, criando layouts organizados para sites.

Principais propriedades

display: grid;

Ativa o sistema de organização em grade.

grid-template-columns

Define a quantidade e o tamanho das colunas.

grid-template-rows

Define o tamanho das linhas.

gap

Define o espaço entre as linhas e colunas.

grid-column

Permite que um elemento ocupe mais de uma coluna.
